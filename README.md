# Action Bar

A simple macropad consists of 5 switches, a rotatry encoder, rp2040, custom pcb and case.

## Dimensions

PCB dimensions: 65.0mm * 84.5mm.
Case Dimension: 81.4mm * 90.0mm.

## BOM

- 5 cherry MX Key Switches
- 1x Rotary Encoder With Switch
- Seeduino XIAO RP2040
- 3D printing
-PCB Manifacture

## Features
- **Compact & Ergonomic:** 5 mechanical switches paired with a multi-functional rotary encoder.
- **Powered by RP2040:** Built using the Seeeduino XIAO RP2040 for reliable performance and easy programmability via QMK/VIAL/CircuitPython.
- **Custom Design:** Features a custom-designed PCB and a 3D-printed enclosure.


## Assembly Instructions
1. **PCB & Soldering:** Solder the Seeeduino XIAO RP2040, switches, and rotary encoder onto the custom PCB.
2. **Enclosure:** Mount the assembled electronics into the 3D-printed case.
3. **Flashing:** Connect via USB-C and flash the firmware.
